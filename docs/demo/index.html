How the scoring works

Every candidate starts at 100. Then:
  • Shorter local parts win — no penalty up to 12 chars, then escalating to -20 past 20.
  • Every trailing digit costs -15. Every suffix costs -8.
  • Pattern bonus: first.last +6 (B2B standard), f.last +4, firstlast +2 …
  • Proton + dot in the local part = -60 (Proton free accounts reject dots).
The exact same scoring runs in the Python CLI — this demo is a faithful port.
